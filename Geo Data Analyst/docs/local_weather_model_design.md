# 이슬점·푄 기반 제주 소지역 국지기상 분석 모델 설계안

작성 2026-10-15. 참조 논문: 이보라 외(2019) "머신러닝 기법의 산림 총일차생산성 예측 모델 비교", 한국농림기상학회지 21(1) 29–41.

## 0. 논문에서 가져오는 설계 원칙

| 논문의 구성 | 이 모델에서의 대응 |
|---|---|
| 정답 자료: 플럭스 타워 점 관측(30분 평균, 표준화 품질관리) | 기상청 AWS·ASOS 지점 관측(분·시 자료). 한라산 고지대 AWS(윗세오름·진달래밭·어리목·성판악 등)가 핵심 |
| 입력 유형 1: 지상 관측 인자만 | 유형 1: AWS 관측 + 지형 인자 (지점에서만 학습 가능) |
| 입력 유형 2: 위성에서 지상 인자와 같은 역할을 하는 인자(MODIS 기온·일사·VPD) | 유형 2: 격자 전역에 존재하는 입력(초단기예보·LDAPS·레이더·GK2A 위성·지형)만 사용 → 모든 셀에 적용 가능 |
| 입력 유형 3: 유형 2 + 위성에서만 얻는 추가 인자(EVI) | 유형 3: 유형 2 + 물리 유도 인자(이슬점·LCL·푄 지수·풍상 노출) |
| MODIS 기온 프로파일을 기온감률로 고도 보정, 픽셀별 회귀로 흐린 날 보완 | 5 km 예보값을 셀 고도로 감률 보정(이미 구현), 결측 시각은 셀별 회귀로 보완 |
| VPD = 포화수증기압 − 현재수증기압(Dingman 2008) | Magnus 식으로 이슬점·VPD·LCL 계산 |
| LM 대조군 + SVM/RF/ANN, R·RMSE·MSE, 연도 분리 검증(2006–13 학습, 2014–15 검증) | 선형 감률 보정(현재 대시보드 값)을 대조군으로 두고 RF·GBM·ANN 비교, 지점 교차검증(leave-one-station-out)과 연도 분리 검증을 병행 |

핵심 결론의 적용: 논문에서 위성 입력만으로도 타워 입력과 같은 정확도(R 0.93)가 나온 이유는 "정답에 직접 대응하는 인자(EVI)"를 넣었기 때문이다. 국지기상에서는 그 역할을 **푄·이슬점 물리 인자**가 맡아야 한다. 기계학습은 물리 인자를 대체하는 것이 아니라, 물리 인자와 관측의 비선형 잔차를 메우는 용도로 쓴다.

## 2. 데이터 활용 방안 구체화

### 2-1. 예측 목표 변수 (셀 × 1시간)

| 목표 | 정의 | 정답 |
|---|---|---|
| 이슬점 온도 Td | Magnus 역산: Td = b·γ/(a−γ), γ = ln(RH/100) + a·T/(b+T), a=17.62, b=243.12 | AWS/ASOS 기온·습도 |
| 상대습도 RH | Td와 셀 기온에서 재계산 | AWS |
| 셀 기온 T | 감률 보정 + 잔차 보정 | AWS |
| 지점기압 P | 해면기압에서 정역학식으로 셀 고도 환산, 모델 잔차 보정 | ASOS·AWS 기압 |
| 체감온도 | 기상청 산식(겨울형 wind chill, 여름형 습도 반영) | 계산값 |
| 풍향·풍속 | 지형 유도 바람(풍상 노출·바람그늘·채널링)을 반영한 셀 바람 | AWS |
| 강수(발생·강도) | 레이더 + 지형성 강화·푄 건조 효과 | 레이더·AWS 우량 |
| 안개·운무 가능성 | T−Td ≤ 1 °C와 LCL이 셀 고도 이하 | GK2A 안개, 고지대 AWS 습도 100 % |

### 2-2. 물리 모듈 (유형 3 인자 생성)

**이슬점 모듈**
- 5 km 점 T·RH → Td(점). 고도에 따른 이슬점 감률 약 1.8–2 °C/km를 적용해 셀 Td를 추정한다(현재 대시보드는 Td를 고도 불변으로 두어 보수적).
- LCL 높이 ≈ 125 m × (T − Td). LCL 고도 = 점 고도 + LCL. 셀 고도 ≥ LCL 고도이면 구름 속(운무) 후보.
- VPD = e_s(T) − e_s(Td). 건조·산불 인자, 증발 냉각 인자.

**푄 모듈 (한라산 횡단)**
- 상류 판정: 셀의 풍향(VEC) 기준 16방위 상류 방향으로 한라산 능선(상류 최고고도 H_up)이 있는지, 셀이 그 바람그늘 안에 있는지(상류 최고고도 − 셀 고도 > 300 m).
- 상류 공기 상태: LDAPS 925/850 hPa 또는 라디오존데의 T·Td·바람. 풍상측 지상 AWS(예: 북서풍이면 애월·한림 쪽, 남동풍이면 서귀포·남원 쪽)의 T·Td를 사용한다.
- 단열 계산: 상류 공기를 LCL까지 건조단열(9.8 °C/km)로 올리고, LCL부터 능선까지 습윤단열(약 5–6 °C/km)로 올린 뒤 능선에서 셀 고도까지 건조단열로 내린다. 결과 기온 T_foehn, 이슬점 Td_foehn(능선 통과 시 수증기 제거).
- 푄 지수 = T_foehn − T_lapse(단순 감률 보정값). 지수가 양수이고 풍속 ≥ 5 m/s, 풍하 측이면 "푄 조건". 보조 지표: 풍하 측 RH 급락(ΔRH ≤ −20 %p/3시간), 풍상·풍하 지점 기온차.
- 이 지수는 (a) 풍하 측 기온·습도 예측의 입력 인자, (b) 건조·산불 경고 셀 판정에 직접 쓴다.

**지형 바람 모듈**
- 풍상 노출(구현됨), 바람그늘 깊이, 계곡 채널링(TPI 음수 + 풍향과 계곡 방향 정렬), 해안 거리로 해풍 보정.

### 2-3. 기계학습 모듈 (논문 방식의 적용)

- **학습 표본**: AWS 지점에 대응하는 셀 × 시각. 입력은 유형 2(격자 전역 입력)와 유형 3(물리 인자 추가)으로 나누어 두 모델을 만들고, 유형 1(지상 관측만)은 상한 기준으로 둔다.
- **대조군**: 현재 대시보드의 선형 감률 보정값(LM 역할).
- **알고리즘**: 랜덤포레스트(결측·이상치에 강함, 논문에서 지상 입력 시 최상), 그래디언트 부스팅, 소형 ANN. 목표별 별도 회귀 모델, 강수·안개는 발생 분류 + 강도 회귀 2단.
- **검증**: ① 연도 분리(예: 2023–2025 학습, 2026 검증), ② 지점 제외 교차검증(한 AWS를 빼고 학습해 그 지점을 예측 → 관측 없는 셀에서의 오차 추정), ③ 사례 검증(푄 사례일, 호우일, 안개일 별도 R·RMSE·MSE).
- **잔차 사용**: 물리 인자 포함 모델의 예측 = 물리값 + 학습된 잔차. 셀로 확장할 때 물리값은 모든 셀에서 계산되고 잔차는 지형 인자로 일반화된다.
- **해석**: RF 변수중요도로 푄 지수·LCL·풍상 노출의 기여도를 보고, 기여가 없으면 모듈을 단순화한다.

### 2-4. 산출과 대시보드 연결

- 셀 × 시각 산출: T, Td, RH, P, 체감온도, 풍향·풍속, 강수 확률·강도, 운무 가능, 푄 조건 플래그, 신뢰 구간(지점 교차검증 RMSE).
- 대시보드 색상 기준에 Td, P, 푄 지수, 예측 RH를 추가하고, 강조 레이어로 "푄 건조·강풍", "운무", "지형성 강수 강화"를 둔다.
- 실시간은 초단기예보·레이더 입력으로 매시 갱신, 학습은 월 1회 재학습.

### 2-6. 한계와 주의

- 5 km 예보값의 계단 효과와 10 m 바람의 지형 미반영은 물리 모듈로 일부만 줄어든다. 셀 단위 정답이 없는 곳의 오차는 지점 교차검증 값으로만 말할 수 있다.
- 푄 모듈은 한라산 단일 능선 가정이다. 오름 군집 지역에서는 상류 최고고도 산정이 거칠다.
- 모든 산출은 분석용이며 기상청 공식 예보·특보를 대신하지 않는다.
